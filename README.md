# Health Assistant 🩺

A simple and interactive Python console application designed to help users track key health metrics.

## Features 
- BMI Calculation: Calculates Body Mass Index and categorizes the weight status (Underweight, Normal, Overweight, Obese).
- Daily Calorie Needs (BMR): Estimates basal metabolic rate and daily calorie requirements using the Mifflin-St Jeor equation based on age, weight, height, and gender.
- Water Intake Tracker: Monitors daily water consumption and provides helpful health tips.

## Technologies Used 
- **Python** (Core logic, `math` module, exception handling)
